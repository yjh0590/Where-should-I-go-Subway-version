# 내리는 문 — 서울 1~9호선 API 연동 단계

기존 밝은 UI와 CSS는 유지하고, 서울 1~9호선 역 좌표와 서울시 실시간 도착정보 API 어댑터를 추가한 버전입니다.

## 포함된 파일

- `index.html`: 기존 화면과 위치·방향 계산, 실제 API 응답 처리
- `data/stations-seoul.js`: 서울 1~9호선 역 좌표 및 분기·순환 경로
- `data/seoul-station-master.csv`: 좌표 데이터의 원본 정리본

## 현재 단계

- 서울 1~9호선의 역 좌표와 13개 운행 경로를 선택할 수 있습니다.
- Ver 2는 더 이상 모의 서버를 사용하지 않습니다.
- 중계 서버의 `/api/subway/arrivals?station=역명` 응답을 서울시 `realtimeStationArrival` 형식으로 처리합니다.
- `subwayHeading`에 왼쪽/오른쪽 값이 있을 때만 API 문 방향을 확정합니다.
- 값이 없으면 문 방향을 추측하지 않습니다.

인증키를 브라우저 코드에 넣지 않기 위해 중계 서버 연결은 4단계에서 추가합니다. 중계 서버가 준비되면 페이지 로드 전에 다음 전역 설정을 제공하면 됩니다.

```js
window.SUBWAY_API_BASE_URL = "https://your-proxy.example.com";
```

## 데이터 출처

- 서울 열린데이터광장 `서울교통공사 역주소 및 전화번호`: 역 좌표
- 서울 열린데이터광장 `서울시 지하철 실시간 도착정보`: 열차 도착 상태와 문 방향 필드

문 방향은 API가 실제 값을 반환한 경우에만 사용하며, 현장 검증 전에는 안전 관련 확정 안내로 간주하면 안 됩니다.
